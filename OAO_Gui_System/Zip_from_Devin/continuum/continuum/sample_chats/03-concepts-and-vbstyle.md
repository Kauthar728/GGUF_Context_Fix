# VBSTYLE and concepts

User: VBSTYLE is my VB style architecture. VB Lang is the language idea behind it. V Drive is the virtual drive concept, also called LangDrive. The V Drive stores LangDrive data.

Assistant: So VBSTYLE uses VB Lang. V Drive is a virtual drive, and LangDrive is the same as V Drive. VBSTYLE contains the Dynamic GUI.

User: CASOS is the whole operating system idea. CASOS contains MemUnit, Truth Surface, and Ghost. Ghost protects CASOS from corruption.

Assistant: CASOS is your knowledge operating system. CASOS contains MemUnit and the Truth Surface. Ghost is a guard for CASOS.

User: A MemUnit stores a knowledge object. The knowledge object holds truth. So MemUnit is a persistent knowledge object, which is a refinement of the older database row idea.

Assistant: Noted. MemUnit evolved from meaning a database row to meaning a persistent knowledge object. That is concept evolution.
